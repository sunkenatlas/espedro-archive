# Espedro 异常生物图鉴 2.0

一份从零制作的电影感城市异常档案。35个独立条目，42幅完整影像，原文引句、详细介绍、关联守则、调查补记与可展开原文。

## 本地打开

Windows 下双击本目录的 `启动预览.cmd`。需要 Node.js 22或以上；当前项目不需要安装 npm 依赖。

也可以在本目录运行：

```powershell
npm run build
npm run dev
```

浏览器访问 **http://127.0.0.1:4175/**。终端按 Ctrl+C 停止服务。若端口已被占用，可先关闭原预览，或设置 `ESPEDRO_PORT` 为其他端口。

请通过本地服务器预览；直接双击HTML文件的 `file://` 模式不能完整运行JavaScript模块。

## 使用

- 首屏“查阅档案”进入目录，`/` 快捷键聚焦检索。
- 可按名称、英文、编号、描述及守则内容搜索，分类和危害特征可组合筛选。
- 右侧按钮切换影像目录与紧凑索引；筛选状态写入URL，可以分享或刷新。
- 点开条目进入独立档案。“返回图鉴”恢复筛选及阅读位置。
- 点击影像查看全幅。滚轮缩放、拖动平移，双击或“1×”复位；手机支持双指缩放。左右方向键切换同一条目的影像，Esc关闭。
- 查看器提供缩放和移动按钮，以及原始PNG文件链接。全屏由浏览器支持决定；被嵌入式浏览器限制时，使用窗口内最大画布并提示。
- 系统开启“减少动态效果”后，页面会关闭非必要动效。

## 文件

| 位置 | 内容 |
| --- | --- |
| `dist/` | 可直接部署的完整成品，含原图与优化图 |
| `data/entities.json` | 35个条目的结构化正文、关联与原文引用 |
| `data/images.json` | 42幅影像的对应关系、类型、尺寸与校验值 |
| `src/` | 页面模板、视觉样式、目录交互与影像查看器 |
| `scripts/` | 构建、本地服务、图片准备与成品检查 |
| `assets/` | 完整原图、WebP展示图、缩略图与内部校对图 |
| `docs/` | 来源索引、实现记录及验证截图 |

所有本次产出均位于 `2.0` 内。原始故事文档、源图片目录、旧站与 `1.0` 不受本项目构建影响。

## 内容维护

编辑 `data/entities.json` 后重新运行 `npm run build`。页面内容来自原作的忠实归纳；“调查补记”属于原设定内的补充研判。原文段落定位保存在 `docs/source-index.md`，其中P表示段落索引，空段落计数，不是页码。

EA编号是网站索引；罗马数字及字母是原文目录分类。危害特征用于检索，不构成完整危险等级。不同版本守则的矛盾和适用情景予以保留。

原图已复制到本项目，构建不依赖上级目录。若要从最初的图片目录重新生成优化图，需要 Python、Pillow（支持WebP），再运行：

```powershell
python scripts/prepare-assets.py
```

影像类型按画面呈现方式编目，不代表核验过的真实拍摄来源。


## 部署

### GitHub Pages

本目录内容作为独立仓库的根目录，包含隐藏的 `.github/workflows/pages.yml`。仓库设置中选择 **Settings → Pages → Build and deployment → Source → GitHub Actions**。

推送到 `main` 后，会自动执行测试、生成网站、检查链接，并部署 `dist`。不需要手动上传构建目录，也不需要配置个人令牌。

工作流读取 GitHub Pages 提供的站点路径，兼容 `用户名.github.io/仓库名/` 项目网站及自定义域名。常规页面使用相对地址；自定义404根据构建时的 `SITE_BASE_PATH` 恢复到本站目录。

本地模拟项目路径构建：

```powershell
$env:SITE_BASE_PATH = '/espedro-archive/'
npm run build
npm run check
Remove-Item Env:SITE_BASE_PATH
```

普通本地预览使用默认根路径，再运行一次 `npm run build` 即可。原图、网页优化图和内容数据随源码保留；`dist` 及内部校对截图不提交到仓库。

### Netlify

将 **`dist` 文件夹** 拖入 Netlify 的手动部署区域即可。也可将本项目作为新站点来源，配置已写入 `netlify.toml`：构建命令 `npm run build`，发布目录 `dist`。

不需要API、后端服务、账号、环境密钥或CDN。该版本没有替换或发布到原网站。
