## 编辑取舍

所有原文均直接从 `E市规则类怪谈.docx` 的 XML 正文读取；没有依赖旧站的转录文件。原始 4,913 个正文段落含空段，以 P1 起算定位。完整映射与原文件摘要见 `source-index.md`。

正文明确区分原文事实、原文推测和基于机制的处置建议。保留薛定谔的外形与复生机制不明、相切与法拉第的人工来源怀疑、塔楼观测不足及高度增长原因不明。没有为这些空白添加确定的新结论。

中立不等于安全：云彩说明伴随黑暗造成的间接风险；尸体、母亲、人群说明无直接袭击也可能污染或同化；哨卡与法拉第说明中立分类和周围攻击行为的区别。变种沿用所属类智慧描述时作出标注，没有新造字母危险等级。

降神按概念性文献整理，保留“异常没有目标”和人类赋予其目标之间的对照，没有编造固定外观或普遍有效的处置程序。黑暗条目另保留名录和后期压制实验的叙事阶段差异。

守则中的强制措施是作品内特定身份、版本的原文，不被编者综合改成现实通用建议。注释说明镜面、声音、数字、学校断言及不同岗位手册的边界。原文出现的《出租车司机备忘录》等题名仅作为原文提及保留，不构建不存在的来源页面或下载链接。
